- **[Download the stable KLBF Lab](https://github.com/PastiiJay/klbf-lab/releases/latest)** (one zip, auto-update, built-in benchmark)

KLBF Lab is a Windows compatibility layer that runs the Xbox Series build of a title from your own files. No game files are included. GPL-3.0.
